# Yamamo Shop

Responsive Roblox shop frontend project created for my portfolio. The project focuses on UI/UX design, interactive shopping flows, and responsive web development.

## Features
- Product catalog with category filtering, searching, and sorting
- Nested farming service categories, including Fisch
- Shopping cart with quantity controls and total calculation
- Checkout and payment-method UI demo
- Order status tracking demo
- Login / registration UI demo
- Responsive layout for desktop and mobile
- Page animations and interactive states
- FAQ and Facebook contact section

## Tech Stack
- HTML5
- CSS3
- JavaScript
- LocalStorage

> This project is a portfolio demo. Authentication and payment flows are UI demonstrations and are not connected to a production backend or real payment processor.
